2. 기각한 방안

(가) 히트 영역만 몰래 넓히기 — 불가

화면을 안 바꾸고 터치만 키우려 했으나, 넓힐 빈 공간이 0px 이다.

공감 글 / 모아보기 / 소모임 공감글 / 정보광장 / 알뜰·장터
  링크 36px · 간격 0px · li 36px · 간격 0px  →  여유 0px

⛔ 이웃 영역을 뺏을 뿐 경계만 옮겨진다. (푸터는 여유 10px 이 있어 이 방법이 통한다 — 별건으로 분리)

(나) 표시 개수를 줄여 홈 길이 유지 — 기각

처음엔 홈이 길어지는 것을 막으려 17→14, 20→16 을 검토했다. 그런데 스크롤 실측이 이를 뒤집었다.

⭐ 93%가 첫 화면에서 끝난다. 아래로 밀리는 글은 원래도 안 눌리던 것이라 홈이 길어져도 손해가 거의 없다. 반대로 개수를 줄이면 93%가 일어나는 첫 화면을 깎는다.

⛔ 이 표본은 오터치 비콘이라 정상 탭이 빠진 편향이 있다. 다만 4화면 이하가 2건뿐인 것은 「거기까지 안 간다」는 신호로 충분히 강하다.

(다) Tailwind py-* 클래스 교체 — 효과 없음

⛔ 처음에 「py-1.5 → py-2.5 로 바꾸면 된다」고 판단했으나 틀렸다.
클래스만 보고 인라인 style 을 안 봤다. 실제로는 인라인이 클래스를 이긴다. 
class="... py-2 ..."                                    ← 무시됨
style="padding-top: calc(0.125rem + var(--row-pad-extra, 0px)); ..."   ← 이게 이긴다

실제 = 2px + 3px(balanced) = 5px  →  실측 5px/5px 과 일치

3. 설계

링크에 min-height: 44px 를 주고 세로 가운데 정렬한다.
padding 을 키우지 않는 이유는 밀도 설정(--row-pad-extra)과 곱해지기 때문이다.
밀도--row-pad-extra현재padding 방식(9px)min-height 방식
compact0px30px44px44px
balanced(기본)3px36px50px44px
relaxed6px42px56px44px

⭐ padding 을 키우면 relaxed 사용자가 56px 로 과해진다. min-height 는 바닥만 보장하므로 그 문제는 없다.

⛔ 2026-09-04 정정 — 「밀도를 크게 쓰는 사람의 설정을 망가뜨리지 않는다」는 틀렸다.
Evaluator 실측: 세 밀도가 전부 44px 로 같아지고 문서 높이도 5582px 로 동일해진다. relaxed(42px)조차 44 미만이라 전부 클램프되기 때문이다. → 이 5개 위젯에서 UI 밀도 설정은 사실상 무효가 된다. ⭐ 그래도 진행하는 이유: 44px 은 접근성 하한이라 그 아래로 내릴 수 없고, 밀도별 차등(44/46/48)을 줘도 compact 회원이 원한 「촘촘함」은 어차피 못 지킨다.

변경 내용 — 5개 파일, 각 1곳

<a class="hover:bg-muted block rounded px-0.5 py-1.5 …"
   style="padding-top: calc(0.125rem + var(--row-pad-extra, 0px)); …">

  ↓ 다음을 추가 (기존 padding·클래스는 그대로 둔다)

   min-height: 44px;
   display: flex;
   flex-direction: column;
   justify-content: center;

⛔ block → flex 로 바뀌므로 자식 레이아웃이 깨지지 않는지 확인이 필요하다. 자식은 <div class="flex items-center gap-1"> 하나뿐이라 위험은 낮지만 실측으로 판정한다.

⭐ 이 변경은 스스로 검증된다. 오터치 계측이 이미 돌고 있어, 배포 후 홈의 dy 10~39px 470건이 줄어드는지로 판정한다.

⛔ 어제 같은 시각과 비교한다. 2시간 전과 비교하면 시간대 차이에 속는다.

⛔ 0 이 되지는 않는다. 오터치의 축은 둘인데(타깃 36px + 인접 간격 0px) 이번 변경은 타깃만 고쳤다. 실측상 간격은 전 67/67=0px → 후 67/67=0px 그대로다. 경계 허용치가 ±18px → ±22px 로 늘어난 것이지 링크가 분리된 것이 아니다. 줄되 남는다는 전제로 판정하라.
